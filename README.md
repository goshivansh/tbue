# TBUE: The Best Utility Extension

You don't need to get a new extension for every other feature you want to add to your browser. TBUE was made to put all the features I (and hopefully you) want into a single extension.

### Features

#### Images:

- Picture in Picture for HTML Images

#### Videos

- Playback Speed control beyond imposed limits (from `0.25x` to `8.0x`)
- Volume boost (upto `500%`)
- Frame Stepping 

> More might be added.
